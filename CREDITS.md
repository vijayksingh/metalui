# Design sources

The life-icon stroke-tint study and the earlier hue/valence, saturation/energy model came from the Kamui design specification, section 02 §3. MetalUI's color foundation revises that model: hue names the kind of feeling, shape carries its strength, and the token palette sets readable stroke pigments for Bone and Graphite.

The gold hairline ring also came from that source vocabulary. Product documentation uses the material's name; this file retains the source attribution.
